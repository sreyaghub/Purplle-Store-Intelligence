# Engineering Choices

## Why YOLOv8?

* Fast inference
* High accuracy
* Easy deployment
* Strong community support

## Why ByteTrack?

* Simple integration
* Stable object identities
* Effective for retail scenarios

## Why FastAPI?

* High performance
* Automatic Swagger documentation
* Easy API development

## Why Streamlit?

* Rapid dashboard development
* Minimal frontend code
* Suitable for hackathon timelines

## Event Storage Choice

JSONL was selected because:

* Simple
* Human readable
* Easy ingestion into analytics pipelines

## Trade-offs

### Advantages

* Fast implementation
* Production-friendly architecture
* Modular design

### Limitations

* Single-camera processing
* No distributed event streaming
* No POS integration

## Future Improvements

* Kafka Event Streaming
* Redis Caching
* PostgreSQL Storage
* Multi-camera Identity Matching
* Real-time Processing
* Conversion Analytics
